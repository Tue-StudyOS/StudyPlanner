# Self-hosted fonts

- `inter-latin.woff2`: Inter variable font, normal weights 300–700.
- `source-serif-4-latin.woff2`: Source Serif 4 variable font, normal weights
  400–700.

Both files are the Latin browser subsets previously served by Google Fonts and
are now bundled by Vite. The corresponding SIL Open Font License texts are kept
beside the files. Do not add another font host or subset without updating the
browser-storage/third-party inventory and checking which scripts the UI needs.
